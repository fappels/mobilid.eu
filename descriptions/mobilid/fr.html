Prérequis
Version minimale d'Android5.1

Installation
L'application Google Play nécessite une connexion à votre Dolibarr avec un certificat SSL valide (https://).
Veuillez nous contacter si vous avez besoin d'une version APK pour un serveur sans certificat SSL valide.
De même, si vos appareils ne prennent pas en charge Google Play, veuillez nous contacter pour le téléchargement de l'APK.
Allez dans le menu Accueil - Configuration - Modules - Déployer un module externe et soumettez le fichier zip du module.
Le module « Connecteur Mobilid » est visible dans la liste des modules et peut être activé et configuré.
Les fonctionnalités optionnelles sont incluses pour un utilisateur. Un code pour les débloquer vous sera envoyé après votre achat.
