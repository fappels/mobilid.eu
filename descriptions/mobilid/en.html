Install
The Google Play application requires a connection to your Dolibarr with a certified SSL certificate (https://).
Please contact us if you need an APK version for a server without a certified SSL certificate.
Also, if your devices do not support Google Play, please contact us for an APK download.
Go into menu Home - Setup - Modules - Deploy an external module and submit the module zip file.
Module 'Mobilid connector' is visible in list of modules and can be activated and configured.
Optional features are included for one user, a code to reveal the features will be sent after your purchase.

Features
Easy management of products - orders - third parties on small screen devices.
Management by automatic barcode reading, no need for search fields.
Various ways to scan barcodes.With the camera for occasional scans.
With a bluetooth handheld for regular scans.
